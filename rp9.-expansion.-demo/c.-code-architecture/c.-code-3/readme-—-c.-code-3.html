META-ABSTRACT

Code 3 — Meta Equilibrium Relational Validator checks exact proportional, reciprocal, complementary, scale, and representational relations within the RP9 / P.B.F. Expansion.
Version 2.1.0 includes exact positional difference, arithmetic reconstruction, relative quotient, positional order, and terminating decimal reconstruction. These additional calculations use positions already calculated by the program’s Base-10 and binary machine-scale controls.

Authoritative arithmetic uses exact rational values. Terminating decimal representations are constructed through integer arithmetic, independently of a fixed Decimal precision.

1. PURPOSE AND INPUT BASIS

The program checks the relations encoded in its controls and records their operations, observations, and status.

Its source basis includes the established P.B.F. rational relations, the assigned functional positions 6–9, Base-10 scaling, and the binary64 machine-scale reference.

The program performs its calculations without reading external numerical data files or accepting an alpha decimal continuation as calculation input.

The rational starting relations and functional position assignments are explicitly encoded in the source. The controls identify their assigned roles and calculate the resulting arithmetic relations.

3. INTEGRATED POSITIONAL CALCULATIONS

The additional controls compare two pairs of calculated positions:

Source control Anchor Compared position
C3_T09 Calculated third scale step: 0.007. Calculated second scale step: 0.07.
C3_T11 Initial exact machine-scale position: 2^-52. Calculated position after three doublings: 2^-49.

For each pair, the program calculates:

  • The exact difference.
  • The reconstructed position.
  • The exact relative quotient.
  • The positional order.
  • Exact terminating decimal representations of the anchor, position, and difference.

These operations check arithmetic consistency of the calculated positions. Reconstruction confirms recovery of the compared position from its anchor and calculated difference.

The recorded relative quotients are 10 for the Base-10 pair and 8 for the binary machine-scale pair.

4. EXACT REPRESENTATION

The program uses Python’s Fraction for exact rational arithmetic.

The decimal formatter factors the reduced denominator into powers of 2 and 5, then constructs the terminating decimal using integer arithmetic.

It raises an error when the rational value has no terminating Base-10 representation. Such values remain available in exact fraction form.

The relative-quotient helper rejects a zero anchor. The positional-order helper supports ABOVE, BELOW, and EQUAL.

The machine-scale control additionally compares its exact reference with the runtime’s binary64 spacing at 1.0 and machine epsilon.

5. EXECUTION

Requirement: Python 3.9 or later, using the standard library.

Run:

python3 CODE_3.py

The program creates 2. OUTPUT beside the executable and writes:

Output file Contents
CODE 3_CONTROL.txt Control statuses, source descriptions, operations, and notes.
CODE 3_DATA.json Structured control results and detailed calculation evidence.
CODE 3_REPORT.md Control summary, functional chain, and global status.

Running the program again replaces these three generated outputs.

The process returns 0 when all controls pass and 1 when a control reports failure.

6. RESULT INTERPRETATION

The global result is:

  • COMPLETE RELATIONAL LOCK — every implemented control reports PASS.
  • RELATIONAL BREAK — at least one implemented control reports FAIL.

The recorded execution of version 2.1.0 produced 17 PASS controls.

The additional decimal checks confirmed exact reconstruction under reduced Decimal precision, including negative, zero, integer, and long terminating values. Nonterminating decimal conversion and division by a zero anchor were also checked.

The global result applies to the implemented conditions and their stated source basis.

C3_T07 registers encoded functional assignments. C3_T12 checks descriptive provenance fields and two specified retired strings in serialized control results. These controls should be read according to those implemented operations.
